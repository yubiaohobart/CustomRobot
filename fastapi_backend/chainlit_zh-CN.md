# 🚀 IntelliServe 智能客服 Chainlit 自测工作台

欢迎来到 **IntelliServe** 智能客服系统全链路交互自测平台！

### 🛠️ 系统架构与核心能力
1. **工作流编排**: `LangGraph` 状态图（意图识别 -> Qdrant 知识召回 -> 上下文记忆融合 -> DeepSeek 生成 / 人工转接）
2. **知识库**: 《XX商城售后服务与退换货政策（2026版）》
3. **向量引擎**: `Qdrant` 纯内存模式 (`:memory:`) + `BGE-M3` 向量检索
4. **大语言模型**: `DeepSeek` (支持 Prompt 注入防御与防幻觉兜底)
5. **服务端口**: 核心后端 `http://127.0.0.1:8000` | 自测 UI `http://localhost:8001`

### 🧪 快速自测提示
- 直接在下方对话框输入您的咨询，或点击快捷操作按钮进行评测。
- 右侧栏将自动呈现 Qdrant 知识库匹配条款，对话流中将展开 LangGraph 各节点执行耗时轨迹。
