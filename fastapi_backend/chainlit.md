# 🚀 IntelliServe 智能客服 Chainlit 自测工作台

欢迎来到 **IntelliServe** 交互式自测平台！

### 🛠️ 架构与链路
1. **工作流编排**: `LangGraph` 状态图 (涵盖 `analyze_query` -> `qdrant_retrieve` -> `memory_synthesis` -> `deepseek_generate` / `human_escalation`)
2. **知识库**: 《XX商城售后服务与退换货政策（2026版）》
3. **向量引擎**: `Qdrant` 内存模式 (`:memory:`) + `BGE-M3` 1024 维稠密向量
4. **大语言模型**: `DeepSeek` (支持 Prompt 注入与防幻觉兜底)
5. **高可用保障**: 极简方案 B 节点级容灾降级 (Graph 异常时秒级纯函数接管)
6. **人工客服与双向协同**: 支持主动转人工/情绪激烈自动升级、坐席工作台接管、Copilot 话术生成、双向对话与工单交接快照

### 🧪 快速自测提示
- **AI 智能问答**: 直接在输入框输入问题，或点击预设动作查看全流程 Trace 步骤与状态流转；
- **🎧 人工客服接入**: 输入“转人工”或点击【🎧 立即转人工客服】，进入人工客服专属接待模式；
- **💬 模拟坐席回复**: 在人工客服模式下，可输入 `/agent <回复内容>` 发送坐席真实回复，或点击【💬 坐席快捷回复】与【💡 AI Copilot 推荐话术】；
- **🤖 切回 AI 模式**: 输入 `/ai` 或点击【🤖 切回 AI 智能接待】即可无缝切换回 AI 托管；
- **📋 查看工单快照**: 输入 `/status` 或点击【📋 查看交接单工单】调阅实时上下文冻结数据。
